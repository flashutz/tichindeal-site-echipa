## Compatibilitate
Design responsive pentru desktop, laptop, tabletă și mobil.
Testare recomandată în Chrome, Edge, Firefox și Safari.

## Cum îl pui pe GitHub
1. Intră pe GitHub și autentifică-te.
2. Apasă **New repository**.
3. Nume recomandat: `tichindeal-site-echipa`.
4. Alege **Public** (dacă profesorul trebuie să vadă site-ul).
5. Creează repository-ul.
6. Apasă **Add file → Upload files**.
7. Încarcă `index.html`, `style.css`, `script.js` și restul fișierelor.
8. Apasă **Commit changes**.
9. Intră în **Settings → Pages**.
10. La Source selectează **Deploy from a branch**.
11. Selectează branch-ul `main` și folderul `/ (root)`.
12. Apasă **Save**.
13. După publicare, GitHub îți va afișa adresa site-ului.

Pentru proiectul școlar, recomand să păstrezi repository-ul cu numele `tichindeal-site-echipa`.
